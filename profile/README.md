## Open-CCW | CCW 开源社区

**Open-CCW** is an open-source organization building third-party tools and ecosystem for **CCW (ccw.fun)** and the **Gandi IDE** — a Scratch 3.0 based creative coding community. / 围绕 CCW（ccw.fun 创意社区）与 Gandi IDE（基于 Scratch 3.0）建设的开源组织。

**Keywords:** CCW, ccw.fun, Gandi IDE, Scratch 3.0, Scratch API, community API, third-party launcher, WebSocket teamwork, custom extension

### Projects / 开源项目

- [ccw-player](https://github.com/open-ccw/ccw-player) — 第三方 CCW 启动器 / third-party CCW launcher
- [gandi-render](https://github.com/open-ccw/gandi-render) — Gandi IDE 渲染器（Vite + TS）/ renderer for Gandi IDE
- [gandi-ccw-api](https://github.com/open-ccw/gandi-ccw-api) — Gandi IDE（Scratch 3.0）工程与素材文件读写 / load & store project and asset files
- [ccw-api-api](https://github.com/open-ccw/ccw-api-api) · [ccw-api-axios](https://github.com/open-ccw/ccw-api-axios) · [ccw-api-request](https://github.com/open-ccw/ccw-api-request) — CCW 社区 API 及请求库 / CCW community API & HTTP clients
- [ccw-api-teamwork](https://github.com/open-ccw/ccw-api-teamwork) · [ccw-api-teamwork-socket](https://github.com/open-ccw/ccw-api-teamwork-socket) — CCW 实时协作 API 与 WebSocket 服务 / real-time teamwork API & socket
- [custom-extension](https://github.com/open-ccw/custom-extension) — Scratch 自定义扩展 / custom Scratch extensions
